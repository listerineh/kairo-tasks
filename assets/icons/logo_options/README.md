# KairoTasks Logo Options

These are SVG logo options for the app icon and branding. They are designed
for the Zen/Calm editorial visual language (sage green `#4A6741` on warm cream
`#FAF9F7`).

To view an option, open the SVG in a browser or image preview.

## Options

### A — `logo_a_leaf_k.svg`
A stylized leaf/teardrop shape with an embedded checkmark. Represents growth,
calm, and completion.

### B — `logo_b_kairos_hourglass.svg`
An abstract hourglass / time-moment shape referencing the Greek *kairos* name.
Simple and iconic.

### C — `logo_c_check_moment.svg`
A clock face with a checkmark, combining the "opportune moment" idea with task
completion.

### D — `logo_d_minimal_k.svg`
A clean, minimal letter "K" with a dot accent. Strong and simple.

## Usage

Once a final option is chosen, rename it to `app_icon.svg` (or the desired
asset name) and place it in the appropriate `assets/` folder. Update the
`pubspec.yaml` assets section if necessary.
